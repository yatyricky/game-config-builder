## M2-1 网格纯逻辑 + 测试

- 文件：`src/grid/layout.ts`、`src/grid/format.ts`、`src/grid/layout.test.ts`、`src/grid/format.test.ts`
- 职责：
  - layout.ts：列布局（left/width）、总宽、画布高、可见行窗口（overscan 越界裁剪）；`ROW_HEIGHT=24` 必须与 grid.css 行高一致
  - format.ts：CellView 三态——string 字段直出文本 / 非 string 字段 notimpl / 缺值（undefined/null）blank；**0 与空串是合法值，不得误判为空**
- 验收：`npm run typecheck` 通过；`npm test` 全绿（含 0 值与空串用例）

## M2-2 网格组件与壳

- 文件：`src/grid/Grid.tsx`、`src/grid/grid.css`、`src/App.tsx`、`src/app.css`
- 职责：
  - Grid：sticky 冻结表头与行头；表头 = `displayName || name`；行头 = 行号 1..N 纯展示；行虚拟滚动（只渲染可见窗口+overscan）；空行补足到 记录数+10；单元格渲染走 format.ts
  - App 壳：打开工程 → 表格下拉（临时载体，M7 换 tab 栏）→ Grid；issues 列表展示；「压测表」开关合成 10 万行走同一 Grid（G3 主观验收用）
  - 不含：冻结列交互（裁决：先不实现）、选中/键盘（M3）、编辑（M5）
- 验收：`npm run build` 通过；浏览器清单见 M2-3
