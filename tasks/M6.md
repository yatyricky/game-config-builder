## M6-1 剪切板纯函数

- 文件：`src/data/clipboard.ts`、`src/data/clipboard.test.ts`
- 职责：
  - `defineImplicitConversion(from, to, fn)` 注册表（spec API 形状）；种子：number→string（spec 示例）；string→number 故意不注册
  - `buildClipboard`：选中区值快照；字段类型标签：标量=type，map/array=组合标签（同标签恒等）
  - `planPaste`：1x1 整板贴一次（越工作区裁剪）；多选须容纳（宽高均 ≥）否则报错；容纳时完整瓦片 tiling（不足一整块边缘不动）；单元格 undefined 原样写（清空）、同类型恒等、跨类型查表、未注册报错并整体阻断
- 验收：typecheck + node:test 全绿（spec tiling 两例逐格断言）

## M6-2 Grid 接线

- 文件：`src/grid/Grid.tsx`、`src/App.tsx`
- 职责：viewport 导航态 ctrl+c 复制 / ctrl+v 粘贴（preventDefault，应用内剪切板）；粘贴走 onApplyWrites 批量写入（复用 applyCellEdit 写时复制通路，value 放宽 unknown）；报错显示在工具栏下方错误行
- 不含：系统剪切板集成（TSV/外部互拷，spec 未要求）
- 验收：`npm run typecheck && npm test && npm run build` 全绿（64 用例）

## M6-3 验收

- 浏览器（`npm run dev`，sample/）：
  1. Effect 表复制 Priority 格（number）→ 选 Name 格 ctrl+v → "1"/"5"/"9" 落格（number→string）
  2. 复制 Name（string）→ 选 Priority 格 ctrl+v → 错误提示「string → number 未定义隐式转换」且数据不变
  3. tiling：复制单格 → 选一列 ctrl+v 整列填充；复制 2x2 → 选 6 宽 3 高 → 前两行 ababab/cdcdcd 第三行不动
  4. 复制 3 宽板 → 2x2 选区 ctrl+v → 报错阻断
  5. 复制 2x2 → 单击一格 ctrl+v → 整板贴一次；末行末列附近贴 → 越界部分裁剪
  6. 复制 Effects 格 → 粘到另一 Effects 格 → 对象恒等落格；编辑清空格 → 粘贴到别处为清空
