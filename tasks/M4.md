## M4-1 选择模型与导航内核 + 测试

- 文件：`src/grid/selection.ts`、`src/grid/selection.test.ts`
- 职责：
  - `Selection { anchor, focus }`（anchor=拖拽锚点）；`selectionBounds`（闭区间）；`isMatrix`
  - `navigate` 总入口，纯函数：
    - 单选：方向键与回车/Tab 系等效方向键、越界不动（M3 语义原样保留，不回绕）
    - 多选：方向键退出矩阵——焦点视同所选单元格原地执行单选步进；回车/Tab 系在矩阵内环流，回绕规则严格按 spec 顺序——Enter 行+1 溢出回矩阵首行且列+1、列溢出回首列；ShiftEnter 对称（行-1 溢出回末行、列-1 溢出回末列）；Tab 列+1 溢出回首列且行+1、行溢出回首行；ShiftTab 对称
  - `focusToMatrixOrigin`：矩阵形成后焦点归位首行首列（spec：焦点默认为矩阵第一行第一列）
- 验收：`npm test` 全绿（M3 单选全量回归 + 环流/回绕/1xN/Nx1/反方向拖拽用例）

## M4-2 Grid 接线

- 文件：`src/grid/Grid.tsx`、`src/grid/grid.css`、`src/grid/cursors.ts`
- 职责：
  - cell mousedown 起点 → mouseenter 延伸 → window mouseup 收尾（网格外释放也能结束）；拖拽模式 cell/col/row
  - 表头 mousedown 选整列、拖拽跨列；行头选整行、拖拽跨行（本质=选满对应行/列的全部单元格）
  - 矩阵除焦点外背景阴影覆盖；焦点粗框沿用；mouseup 后 `focusToMatrixOrigin` 归位
  - 键盘统一走 `navigate`；`user-select: none`；指针 CSS_SIZE 22→20
  - 不含：跨工作区选择、排序筛选、编辑
- 验收：`npm run build` 通过；浏览器清单见 M4-3

## M4-3 验收

- 命令：`npm run typecheck && npm test && npm run build` 全绿
- 浏览器（打开 `sample/`，选 Skill）：
  1. 点击 cell 拖拽：形成矩阵阴影，松手后焦点=矩阵首行首列且粗框
  2. 反方向拖拽（右下→左上）矩阵同样正确
  3. 表头点击选整列；表头拖拽选多列；行头点击/拖拽选行
  4. 矩阵内 Enter/Shift+Enter/Tab/Shift+Tab 按环流规则移动，越界回绕逐条对照 spec（含单行矩阵、单列矩阵）
  5. 方向键立即退出多选，从焦点位置继续单选导航
  6. 指针尺寸再缩 10% 后三态形态仍正确
