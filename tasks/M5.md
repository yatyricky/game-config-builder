## M5-2 Grid 编辑态

- 文件：`src/grid/Grid.tsx`、`src/grid/grid.css`、`src/App.tsx`
- 职责：
  - 双态控件：string 字段导航态 div / 编辑态 text input；非 string 不可进入编辑（保持 NotImplemented 占位）
  - 三进入径：双击（首次点击已按 M3 语义丢失多选）；F2（单选/多选均可，只编辑焦点、矩阵保持）；导航态直接键入——可打印字符与 IME（Process/isComposing/keyCode 229）经 flushSync 同步挂载并聚焦输入框，不消费事件，首字符/组合落在输入框
  - 提交：Enter/ShiftEnter/Tab/ShiftTab 提交后执行该键导航态行为（矩阵保持则环流）；编辑中点击任何单元格/行列头先提交再选中；Esc 取消恢复原值
  - 编辑态方向键只操作输入框（上下=caret 首尾，左右=默认）；提交写内存：App 写时复制更新表数据（稀疏补齐即时重渲染），不写盘（M7）
- 验收：`npm run typecheck && npm test && npm run build` 全绿（51 用例）

## M5-3 验收

- 浏览器（`npm run dev`，打开 sample/ 选 Skill）：
  1. 双击 Strike 的 Name → input 出现带原值；改值回车 → 新值渲染、焦点下移
  2. Tab/Shift+Tab 提交横移；多选矩阵 F2 只编辑焦点，提交后 Enter 在矩阵内环流
  3. Esc 恢复原值
  4. 导航态直接敲字母 / 中文 IME → 直接进入编辑态且首字符不丢
  5. 编辑中点其他单元格 → 提交再选中
  6. 空行（第 3 行起）直接输入提交 → 即时落为记录行（保存侧压缩/拦截 M7 生效）
  7. 非 string 列双击/F2/键入 → 无编辑态（保持灰斜体）
