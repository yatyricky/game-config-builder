## M3-1 纯逻辑选择内核 + 测试

- 文件：`src/grid/selection.ts`、`src/grid/selection.test.ts`
- 职责：
  - `Focus {row, col}`（工作区坐标）、`DEFAULT_FOCUS = {0,0}`
  - `moveFocus(focus, key, rowCount, colCount)`：四方向 + 回车系（Enter=下、ShiftEnter=上）+ Tab 系（Tab=右、ShiftTab=左）；四条边界不生效；**不回绕**（回绕是 M4 矩阵行为）；空工作区不动；不修改入参
  - `navKeyOf(key, shiftKey)`：键盘事件 → NavKey，其余返回 null

## M3-2 Grid 接线 + 三态指针

- 文件：`src/grid/Grid.tsx`、`src/grid/cursors.ts`、`src/grid/grid.css`、`src/App.tsx`
- 职责：
  - viewport `tabIndex=0` 接键盘，命中导航键一律 `preventDefault`（阻断原生滚动/焦点跳转）
  - 点击 cell 选中；焦点粗框（`outline` + 提升层级盖过邻格边框）
  - 焦点变化后滚入视口：垂直贴边；水平考虑 sticky 行头 48px 遮挡补偿
  - 三态指针（canvas 绘制 → PNG data URI → CSS 变量；Chrome 不支持 SVG cursor）：工作区 = Excel 粗体空心十字 + 硬阴影、表头 = ⇩、行头 = ⇨
  - 表格切换重置焦点：App 侧 `key={表名}` remount
  - 不含：表头/行头点击选择（M4）、编辑（M5）
- 验收：`npm run build` 通过；浏览器清单见 M3-3
