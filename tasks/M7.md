## M7-2 存储层 + 自动保存管线

- 文件：`src/data/dirSource.ts`（fsaWriteFile：getFileHandle create+createWritable）、`src/data/recents.ts`（localStorage 名单去重上限 5；IndexedDB 'gcb-handles'/handles 存句柄）、`src/App.tsx`
- 管线：markDirty（编辑/粘贴）→ 1s 防抖 doSave → 逐脏表 validateRows（不过：红色错误行报「表 X 第 n 行缺少必填…」并保留 dirty 等下次编辑重试）→ compactRows → fsaWriteFile 写 `表名.json` → 内存同步压缩（前端立即响应）→ 清 dirty；保存按钮 flush；beforeunload 在 dirty 非空时弹警告；打开工程 showDirectoryPicker({mode:'readwrite'})；打开/重开成功即记 recents + 存句柄；下拉选近期 = getHandle + requestPermission + loadProject
- 验收：`npm run typecheck && npm test && npm run build` 全绿（73 用例）
